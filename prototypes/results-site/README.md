# Public results site prototype

Throwaway prototype for [What does the public results site show for each day status?](https://github.com/Turbo87/keyhole/issues/29).

Open `index.html` in a browser. The control panel sets each class day's status, the approval state, cancelled days with launches and days that fail the 25% day validity rule. The bottom bar switches between three layouts (`?variant=A|B|C`). The layouts are only a vehicle for seeing the status rules on realistic pages and are not part of the decision.
