# Printable results prototype

Throwaway prototype for [What do the printable daily and overall result pages contain?](https://github.com/Turbo87/keyhole/issues/85).

Open `index.html` in a browser. The bottom bar switches between three variants (`?variant=A|B|C`): the public results page with a print stylesheet, a separate scorer notice-board sheet rendered from the published snapshot, and a scorer printout of the working state. The control panel sets the page, the day status and unpublished edits, and "Paper preview" applies the A4 print layout on screen. The browser's print dialog shows the real print output.
